# Contributing

ztcl is experimental. Open an issue before a large change.

1. Read [WRITING.md](WRITING.md) and [AGENTS.md](AGENTS.md).
2. Run `zig build test` and `tools/suite.sh`. The pass counts must not drop.
3. Open a PR. PRs merge by rebase.

Contributions are licensed under BSD-2-Clause. Do not submit code copied from Tcl or from a project with a copyleft license.
