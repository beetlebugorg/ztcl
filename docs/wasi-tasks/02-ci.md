# Task 02: the smoke tests and the CI job under wasmtime

Platform: shared/wasi.

## Goal

`tools/wasi-smoke.sh` and `tools/wasi-run.sh` exist, and CI runs the WASI build on each push.

## Files

- `tools/wasi-run.sh`: runs `zig-out/bin/ztcl.wasm` under wasmtime with the same arguments as `zig-out/bin/ztcl`. The current folder is the preopen `/`. `tools/suite.sh -r tools/wasi-run.sh` uses it as the runner.
- `tools/wasi-smoke.sh`: the scripts of task 01, plus a test that each capability is absent by default, and a test that `exec`, `thread`, and `socket` are absent.
- `.github/workflows/ci.yml`: a job `wasi`. It downloads the pinned wasmtime release, checks its SHA-256, builds, and runs `tools/wasi-smoke.sh`.

## Acceptance

```sh
CAP zig build -Dtarget=wasm32-wasi
CAP tools/wasi-smoke.sh
CAP tools/suite.sh -t core-8-6-16 -r tools/wasi-run.sh -o zig-out/suite-wasi.txt   # report the count
```

The suite count under WASI is a baseline in this task, with no gate. Put the count of each file in the PR body. The CI job passes on the PR.
