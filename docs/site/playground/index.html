This page runs the WebAssembly build of ztcl in a Web Worker. The script has no access to the network or to files. The step limit and the memory limit stop it. The WebAssembly guide shows how to do this in your own page.

script.tclTab indents · Ctrl+Enter runs

Each run starts a new interpreter. The output of puts shows when the script ends. The memory limit is a cap of the heap. The linear memory of the worker can grow to twice the limit, and it goes back to the browser at the next run.
