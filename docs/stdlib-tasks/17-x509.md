# Task 17: PEM, keys, X.509 chains, and root stores

Platform: shared.

## Goal

The chain validation of the design on the parse of `std.crypto.Certificate`.

## Files

- `src/tls/pem.zig` (new): PEM chains, PKCS#8, SEC 1 EC keys, and Ed25519 keys.
- `src/tls/chain.zig` (new): path building, `basicConstraints`, key usage, extended key usage, name constraints, unknown critical extensions, dates, and the host name.
- `src/tls/roots.zig` (new): the system store through `Bundle.rescan`, a PEM file under the root folder, or bytes from the embedder (`Interp.tls_roots`).

## Test sources

- The x509-limbo test suite (path validation cases).
- The Wycheproof ECDSA and Ed25519 signature sets.
- RFC 5280, and the host name rules of RFC 6125.

## Acceptance

```sh
CAP zig build tls-x509-test -- path/to/x509-limbo/limbo.json
CAP zig build x509-fuzz -- --seconds 600
```

Gates:

- Each x509-limbo case of the profiles that the PR lists gives the expected result. Each skip has a reason.
- A leaf certificate used as a CA is refused, and a test shows that `Parsed.verify` alone accepts it.
