# Task 43: RV64 in CI and the docs

## Goal

A CI job on Linux that builds for `riscv64-linux-musl` and runs the acceptance commands of tasks 41 and 42 under `qemu-riscv64`, and the docs of the port.

## Files

- `.github/workflows/ci.yml`, `docs/jit.md`, `docs/install.md`, `docs/dev/jit.md`.

## Rules

- The job installs qemu from the package manager of the runner image. It uses no action from outside GitHub.
- The docs say that RV64 runs under qemu in CI and that no test runs on RV64 hardware, until a test does.
