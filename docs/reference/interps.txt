# The command reference: interpreters and packages. The format is in
# docs/reference/README.md.

== interp
syn: interp cmd ?arg ...?
does: Makes and runs child interpreters. A child has its own commands and variables, and never more capabilities than its parent. An alias is a command of a child that runs a command of the parent, and is the way to give a child one exact power.
cap: interp
flags: --allow interp
sub: interp create ?-safe? ?-meter NAME? ?--? ?PATH? | A new child, and its path. `-meter` (capability `meter`) counts the child in a meter of `ztcl::meter`.
sub: interp eval PATH ARG ?ARG ...? | Runs a script in the child.
sub: interp alias SRCPATH SRCCMD TARGETPATH TARGETCMD ?ARG ...? | Makes SRCCMD of the child run TARGETCMD of the parent.
sub: interp aliases ?PATH? | The aliases of a child.
sub: interp delete ?PATH ...? | Removes children.
sub: interp exists PATH | 1 when the child exists.
sub: interp children ?PATH? | The children.
sub: interp cancel ?-unwind? ?--? ?PATH? ?RESULT? | Stops the script of the interp with the error "eval canceled", or RESULT. With -unwind, `catch` does not stop the error.
sub: interp slaves ?PATH? | The old name of `children`.
sub: interp issafe ?PATH? | 1 for a safe interpreter.
sub: interp hide PATH CMD ?NAME? | Hides a command from the scripts of the child.
sub: interp expose PATH NAME ?CMD? | Makes a hidden command visible again.
sub: interp hidden ?PATH? | The hidden commands.
sub: interp invokehidden PATH ?-global? NAME ?ARG ...? | Runs a hidden command.
sub: interp marktrusted PATH | Makes a safe child trusted.
sub: interp recursionlimit PATH ?N? | The nesting limit of the child.
sub: interp target PATH ALIAS | The target of an alias.
ex: set c [interp create]; interp eval $c {expr {6 * 7}} => 42
ex: interp alias $c double {} apply {{x} {expr {$x * 2}}}; interp eval $c {double 4} => 8
diff: `interp limit` is not in ztcl. Each interpreter has the compute limit and the memory limit of the host instead.

== package
syn: package option ?arg ...?
does: Loads packages by name and version. With the capabilities package and file, the handler `tclPkgUnknown` reads the `pkgIndex.tcl` file of each folder of `auto_path` and of each folder in it, as Tcl does. A script can also run `package ifneeded` itself. A build with modules loads the built-in `ztcl::` modules by name. With no capability, only `names`, `present`, `provide`, `require`, and `versions` exist.
sub: package require ?-exact? NAME ?VERSION ...? | Loads a package and gives its version.
sub: package provide NAME ?VERSION? | Says that the package is loaded, or gives its version.
sub: package ifneeded NAME VERSION ?SCRIPT? | The script that loads a version.
sub: package present ?-exact? NAME ?VERSION? | The version of a loaded package, or an error.
sub: package names | The names of the known packages.
sub: package versions NAME | The versions of a package that `ifneeded` knows.
sub: package forget ?NAME ...? | Forgets packages.
sub: package vcompare V1 V2 | -1, 0, or 1.
sub: package vsatisfies VERSION REQ ?REQ ...? | 1 when VERSION fits a requirement such as `1.2`, `1.2-`, or `1.2-2.0`.
sub: package prefer ?latest|stable? | Which versions `require` picks.
sub: package unknown ?CMD? | The command that runs for a missing package.
ex: package require ztcl::json => 1.0
ex: package provide jot 0.1.0; package present jot => 0.1.0

== safe::interpCreate
syn: safe::interpCreate ?child? ?-accessPath LIST? ?-statics BOOL? ?-noStatics? ?-nested BOOL? ?-nestedLoadOk? ?-deleteHook SCRIPT?
does: The safe package 0.10 of the Tcl library (the Safe Base), which loads at the first call of one of its commands: a safe child with aliases into the parent for `source`, `load`, `glob`, `encoding`, `exit`, `clock`, and the `file` subcommands that read no file. The child sees each directory of its access path only as a token, `$p(:N:)`. An alias turns the tokens back into the directories and checks each path against the access path. `interpInit` sets up a child that exists, `interpConfigure` reads or changes the options, `interpAddToAccessPath` and `interpFindInAccessPath` give the token of a directory, `interpDelete` runs the delete hook and deletes the child, and `setLogCmd` sets a command for the messages of each check.
cap: package
flags: --allow package,interp
names: safe::interpInit safe::interpConfigure safe::interpDelete safe::interpAddToAccessPath safe::interpFindInAccessPath safe::setLogCmd
ex: set c [safe::interpCreate -accessPath {/a /b}]; safe::interpFindInAccessPath $c /b => $p(:1:)
ex: interp eval $c {expr {6 * 7}} => 42
diff: A safe child of ztcl has no hidden commands, so the source alias reads the file in the parent and evaluates its text in the child. The child has the small `package` command, which runs no `ifneeded` script.

== tclPkgUnknown
syn: tclPkgUnknown name ?version ...?
does: The handler of `package unknown`: sources the `pkgIndex.tcl` file of each folder of `auto_path` and of each folder in it, once. A `pkgIndex.tcl` runs with the variable `dir` set to its folder.
cap: package
flags: --allow package
names: tclPkgUnknown tclPkgSetup tclLog

== auto_load
syn: auto_load command ?namespace?
does: Defines a command from `auto_index`, which the `tclIndex` files of `auto_path` and `tclPkgSetup` (the lazy `pkgIndex.tcl` form) fill. Gives 1 when the command exists after it. The `unknown` command calls it for a missing command.
cap: package
flags: --allow package
names: auto_load auto_load_index auto_reset auto_qualify auto_import auto_execok
ex: auto_qualify foo ::bar => ::bar::foo foo

== history
syn: history ?option? ?arg ...?
does: The list of the commands of a session, as in Tcl: `add`, `change`, `clear`, `event`, `info`, `keep`, `nextid`, and `redo`.
cap: package
flags: --allow package
ex: history add {set a 1}; history nextid => 2
