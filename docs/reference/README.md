# Commands

Each command of ztcl has a page: its synopsis, what it gives, its options and subcommands, examples that run in the shell of the page, its errors, the capability that it needs, and how it differs from Tcl 8.6. A command with a capability has its name in a tag: a new interpreter does not have it until the host turns the capability on.

For agents, [api.json](https://beetlebug.org/ztcl/reference/api.json) has the same facts for each command, and [llms-full.txt](https://beetlebug.org/ztcl/llms-full.txt) has the Markdown of each page.
