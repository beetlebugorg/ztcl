# The command reference: strings. tools/reference.py reads each file of
# this folder. The format is in docs/reference/README.md.

== tcl::prefix
syn: tcl::prefix subcommand ?arg ...?
does: Matches a word to a unique prefix of a table, as a command does with its options.
sub: tcl::prefix match ?-exact? ?-message TEXT? ?-error OPTIONS? TABLE STRING | The entry of TABLE that STRING is a unique prefix of, or an error.
sub: tcl::prefix all TABLE STRING | Each entry that starts with STRING.
sub: tcl::prefix longest TABLE STRING | The longest common prefix of those entries.
ex: tcl::prefix match {apple banana} ban => banana
ex: tcl::prefix all {apple apricot banana} ap => apple apricot

== append
syn: append varName ?value ...?
does: Adds each value to the end of the string in the variable, and gives the new value. It makes the variable when it has no value.
ex: set s buy; append s " " milk => buy milk

== concat
syn: concat ?arg ...?
does: Joins the arguments with one space, after it removes the white space at the ends of each one. Each argument that is a list stays a list, so `concat` of lists is one flat list.
ex: concat {a b} {c d} => a b c d

== format
syn: format formatString ?arg ...?
does: Makes a string from a template, as `printf` of C does. `%s` is a string, `%d` an integer, `%f`, `%e`, and `%g` a float, `%x` hexadecimal, `%c` a character from its code, and `%%` a percent sign. A flag such as `-`, `0`, or `+`, a width, and a precision go between `%` and the letter. `%2$s` takes the second argument.
ex: format "%-5s|%05.1f" ab 3.14159 => ab   |003.1
ex: format %x 255 => ff
err: format %d abc | expected integer but got "abc"

== scan
syn: scan string format ?varName ...?
does: Reads values from a string with a template of `format`. With variables, it sets them and gives the count of values that it read. Without variables, it gives the values as a list.
ex: scan "12 apples" "%d %s" => 12 apples
ex: scan "x=7" "x=%d" n => 1

== split
syn: split string ?splitChars?
syn: split string splitChars -grapheme
does: Makes a list: it cuts the string at each character of splitChars (white space by default). Two separators in a row give an empty element. An empty splitChars cuts between each character. With `-grapheme`, the unit is the grapheme cluster: an empty splitChars gives each cluster, and a split character cuts only where it is a whole cluster. The form with `-grapheme` needs the module ztcl::text in the build.
ex: split "a,b,,c" , => a b {} c
ex: split abc "" => a b c
ex: llength [split "e\u0301x" "" -grapheme] => 2
diff: The form with `-grapheme` is new in ztcl. It has three arguments, so in Tcl it is an error.

== join
syn: join list ?joinString?
does: Makes a string of the elements of a list, with joinString (one space by default) between them.
ex: join {a b c} ", " => a, b, c

== regexp
syn: regexp ?-option ...? exp string ?matchVar? ?subMatchVar ...?
does: Finds the regular expression exp in string. It gives 1 for a match and 0 for no match, and sets matchVar to the match and each subMatchVar to a group. Put exp in braces, so that Tcl does not change its backslashes.
opt: -nocase | Matches letters with no case.
opt: -all | Finds each match. It gives the count of matches.
opt: -inline | Gives the match and its groups as a list, and sets no variable. With `-all`, each match and its groups.
opt: -indices | Gives the start and end index of each match in place of the text.
opt: -start INDEX | Starts the search at INDEX.
opt: -line | `^` and `$` match at each line, and `.` does not match a newline.
opt: -expanded | White space and `#` comments in exp are ignored.
opt: -about | Gives the count of groups and the flags of exp.
ex: regexp -inline {(\d+)-(\d+)} "pages 12-40" => 12-40 12 40
ex: regexp -all -inline {#\w+} "a #b c #d" => {#b} #d
ex: regexp {^\d+$} 42abc => 0
err: regexp {(} x | couldn't compile regular expression pattern: parentheses () not balanced

== regsub
syn: regsub ?-option ...? exp string subSpec ?varName?
does: Replaces the matches of exp in string with subSpec, and gives the new string. In subSpec, `&` and `\0` are the match, and `\1` to `\9` are the groups. With varName, it puts the string in the variable and gives the count of replacements.
opt: -all | Replaces each match. Without it, only the first.
opt: -nocase | Matches letters with no case.
opt: -start INDEX | Starts the search at INDEX.
ex: regsub -all {\s+} "a   b  c" " " => a b c
ex: regsub -all {#(\w+)} "x #a #b" {<\1>} => x <a> <b>

== subst
syn: subst ?-nobackslashes? ?-nocommands? ?-novariables? string
does: Does the substitutions of Tcl on a string: `$name`, `[script]`, and backslashes. A flag turns one of them off. Use it only on text that you trust: `subst` runs each command in brackets.
ex: set n 3; subst {n is $n} => n is 3
ex: subst -nocommands {[x] $tcl_platform(engine)} => [x] ztcl

== encoding
syn: encoding option ?arg ...?
does: Changes text to bytes and back. ztcl stores text as UTF-8.
cap: channels
flags: --allow channels
sub: encoding convertto ?-profile PROFILE? ?-failindex VAR? ENCODING STRING | The bytes of STRING in ENCODING, as a byte string. The options are in Tcl 9.1 only.
sub: encoding convertfrom ?-profile PROFILE? ?-failindex VAR? ENCODING BYTES | The text of BYTES in ENCODING. In Tcl 9.1 the default profile `strict` makes a bad byte an error, and `-failindex VAR` gives the text before it and puts its index in VAR. The profile `replace` puts U+FFFD for a bad byte, and `tcl8` keeps the behavior of Tcl 8.6. The options are in Tcl 9.1 only.
sub: encoding profiles | The profiles: `replace strict tcl8`. Tcl 9.1 only.
sub: encoding user | The encoding of the user: utf-8. Tcl 9.1 only.
sub: encoding names | The names of the encodings: the ones with no table, and the files of the encoding folders.
sub: encoding system | The encoding of the system: utf-8.
sub: encoding dirs ?LIST? | The folders of the encoding files of Tcl (`koi8-r.enc`, `iso2022-jp.enc`, ...). ztcl reads a file on the first use of its encoding, from these folders. Before a script sets the list, the folder is `$tcl_library/encoding`. The binary has no tables.
ex: string length [encoding convertto utf-8 é] => 2

== binary
syn: binary subcommand ?arg ...?
does: Packs values into bytes and reads values from bytes, with a template of letters such as `c` (8 bits), `s` (16 bits, little endian), `S` (big endian), `i` and `I` (32 bits), `w` and `W` (64 bits), `f` and `d` (floats), `a` (bytes), and `H` (hexadecimal). A count or `*` follows a letter.
sub: binary format TEMPLATE ?VALUE ...? | Gives the bytes.
sub: binary scan BYTES TEMPLATE ?VAR ...? | Sets the variables and gives the count of values that it read.
sub: binary encode FORMAT ?-option value ...? DATA | `base64`, `hex`, or `uuencode` text of the bytes.
sub: binary decode FORMAT ?-option value ...? DATA | The bytes of the text.
ex: binary encode hex [binary format S 258] => 0102
ex: binary scan [binary format c3 {1 2 3}] c* l => 1
ex: binary encode base64 hello => aGVsbG8=

== tcl_endOfWord
syn: tcl_endOfWord str start
does: The index after the end of the first word that ends after start, or -1. `tcl_startOfNextWord`, `tcl_startOfPreviousWord`, `tcl_wordBreakAfter`, and `tcl_wordBreakBefore` find the other edges of words. A word is a run of letters, digits, and underscores.
names: tcl_startOfNextWord tcl_startOfPreviousWord tcl_wordBreakAfter tcl_wordBreakBefore
ex: tcl_endOfWord "buy milk" 0 => 3
ex: tcl_startOfNextWord "buy milk" 0 => 4
