# The command reference: math. The format is in docs/reference/README.md.

== expr
syn: expr arg ?arg ...?
does: Computes an expression with the operators of C and the math functions. Put the expression in braces: then `expr` does its own substitution, a value from a variable stays a value, and the expression is compiled once. Integers have no fixed size. An integer divided by an integer is an integer, rounded down.
ex: expr {2 ** 100} => 1267650600228229401496703205376
ex: expr {7 / 2} => 3
ex: expr {-7 / 2} => -4
ex: expr {7 / 2.0} => 3.5
ex: expr {"a" eq "a" ? "same" : "other"} => same
ex: expr {5 in {1 5 9}} => 1
err: expr {1 / 0} | divide by zero
err: expr {"ten" + 1} | can't use non-numeric string as operand of "+"
diff: The operators `eq`, `ne`, `in`, and `ni` compare strings and lists, as in Tcl 8.6.

== incr
syn: incr varName ?increment?
does: Adds increment (1 by default) to the integer in a variable, and gives the new value. It makes the variable with 0 first when it has no value.
ex: set n 5; incr n -2 => 3
err: set s abc; incr s | expected integer but got "abc"

== tcl::mathfunc
syn: tcl::mathfunc::NAME ?arg ...?
does: The functions of `expr`, each one also a command in this namespace. `abs`, `ceil`, `floor`, `round`, `int`, `wide`, `entier`, `double`, `bool`, `sqrt`, `isqrt`, `exp`, `log`, `log10`, `pow`, `fmod`, `hypot`, `max`, `min`, `sin`, `cos`, `tan`, `asin`, `acos`, `atan`, `atan2`, `sinh`, `cosh`, `tanh`, `rand`, and `srand`. A proc in this namespace adds a function to `expr`.
names: tcl::mathfunc::abs tcl::mathfunc::acos tcl::mathfunc::asin tcl::mathfunc::atan tcl::mathfunc::atan2 tcl::mathfunc::bool tcl::mathfunc::ceil tcl::mathfunc::cos tcl::mathfunc::cosh tcl::mathfunc::double tcl::mathfunc::entier tcl::mathfunc::exp tcl::mathfunc::floor tcl::mathfunc::fmod tcl::mathfunc::hypot tcl::mathfunc::int tcl::mathfunc::isqrt tcl::mathfunc::log tcl::mathfunc::log10 tcl::mathfunc::max tcl::mathfunc::min tcl::mathfunc::pow tcl::mathfunc::rand tcl::mathfunc::round tcl::mathfunc::sin tcl::mathfunc::sinh tcl::mathfunc::sqrt tcl::mathfunc::srand tcl::mathfunc::tan tcl::mathfunc::tanh tcl::mathfunc::wide
ex: expr {max(3, 9, 4)} => 9
ex: expr {round(2.5)} => 3
ex: expr {isqrt(17)} => 4
ex: proc tcl::mathfunc::twice {x} {expr {$x * 2}}; expr {twice(21)} => 42
diff: `rand()` has a fixed seed in a new interpreter, so that a script with no capability gives the same output each run.

== tcl::mathfunc::trunc
syn: tcl::mathfunc::NAME arg ?arg ...?
does: The math functions of Tcl 9.1: the functions of C99 `acosh`, `asinh`, `atanh`, `cbrt`, `copysign`, `dim` (fdim of C), `erf`, `erfc`, `exp2`, `expm1`, `fma`, `gamma` (tgamma of C), `ldexp`, `lgamma`, `log1p`, `log2`, `logb`, `nextafter`, `remainder`, and `trunc`, and the tests `isfinite`, `isinf`, `isnan`, `isnormal`, `issubnormal`, `isunordered`, and `signbit`. Each function except a test gives a double. A test gives 0 or 1, and it takes NaN, an integer of any size, or a double.
tcl: 9.1
names: tcl::mathfunc::acosh tcl::mathfunc::asinh tcl::mathfunc::atanh tcl::mathfunc::cbrt tcl::mathfunc::copysign tcl::mathfunc::dim tcl::mathfunc::erf tcl::mathfunc::erfc tcl::mathfunc::exp2 tcl::mathfunc::expm1 tcl::mathfunc::fma tcl::mathfunc::gamma tcl::mathfunc::isfinite tcl::mathfunc::isinf tcl::mathfunc::isnan tcl::mathfunc::isnormal tcl::mathfunc::issubnormal tcl::mathfunc::isunordered tcl::mathfunc::ldexp tcl::mathfunc::lgamma tcl::mathfunc::log1p tcl::mathfunc::log2 tcl::mathfunc::logb tcl::mathfunc::nextafter tcl::mathfunc::remainder tcl::mathfunc::signbit
ex: expr {trunc(-2.5)} => -2.0
ex: expr {log2(8)} => 3.0
ex: expr {remainder(7, 2)} => -1.0
ex: expr {isnan(NaN)} => 1
ex: expr {signbit(-0.0)} => 1
err: expr {log2(-1)} | domain error: argument not in valid range
err: expr {trunc("a")} | expected floating-point number but got "a"
diff: The functions come from `std.math` of Zig. The last digit of a result can differ from tclsh 9.1.0, which gives 3.0000000000000004 for `cbrt(27)`. tclsh gives the error "floating-point value too large to represent" for some results below 2**-1022, such as `asinh(1e-310)`, and ztcl gives the result.

== tcl::mathop::lt
syn: tcl::mathop::lt ?arg ...?
does: The string order operators of Tcl 9.1: `lt`, `gt`, `le`, and `ge`. In `expr` they compare two values as strings, with the precedence of `<`. As a command, each one gives 1 when each pair of neighbor arguments is in the order.
tcl: 9.1
names: tcl::mathop::gt tcl::mathop::le tcl::mathop::ge
ex: expr {"10" lt "9"} => 1
ex: expr {"b" ge "a"} => 1
ex: tcl::mathop::lt a b c => 1

== divmod
syn: divmod dividend divisor
does: The quotient and the remainder of two integers of any size, as a list. The quotient is rounded down, as `/` of `expr` does, so the remainder has the sign of the divisor.
tcl: 9.1
ex: divmod 7 2 => 3 1
ex: divmod -7 2 => -4 1
err: divmod 7 0 | divide by zero
err: divmod 7.5 2 | dividend must be an integer
diff: tclsh 9.1.0 gives a wrong quotient for `divmod 9223372036854775807 -1` and ends with SIGFPE for `divmod -9223372036854775808 -1`. ztcl gives the exact result.

== fpclassify
syn: fpclassify floatValue
does: The class of a number: `zero`, `subnormal`, `normal`, `infinite`, or `nan`.
tcl: 9.1
ex: fpclassify 1.5 => normal
ex: fpclassify 1e-310 => subnormal
ex: fpclassify Inf => infinite

== frexp
syn: frexp floatValue
does: The fraction and the exponent of a double, as a list. The fraction is from 0.5 to 1, and the value is the fraction times 2 to the exponent.
tcl: 9.1
ex: frexp 10 => 0.625 4
ex: frexp -3 => -0.75 2

== modf
syn: modf floatValue
does: The integer part and the fraction part of a double, as a list. Both parts have the sign of the value.
tcl: 9.1
ex: modf 2.5 => 2.0 0.5
ex: modf -2.5 => -2.0 -0.5

== remquo
syn: remquo dividend divisor
does: The remainder of `remainder()` and the low 3 bits of the rounded quotient with the sign of the quotient, as a list.
tcl: 9.1
ex: remquo 7 2 => -1.0 4
ex: remquo 100 3 => 1.0 1
err: remquo 7 0 | domain error: argument not in valid range
diff: tclsh 9.1.0 gives NaN and an undefined quotient for a zero divisor or an infinite dividend. ztcl gives a domain error, as `remainder()` does.

== tcl::mathop
syn: tcl::mathop::OP ?arg ...?
does: Each operator of `expr` as a command: `+`, `-`, `*`, `/`, `%`, `**`, `<<`, `>>`, `&`, `|`, `^`, `~`, `!`, `==`, `!=`, `<`, `<=`, `>`, `>=`, `eq`, `ne`, `in`, and `ni`. `+` and `*` take any count of arguments. Import them with `namespace path tcl::mathop` to write `+ 1 2`.
names: tcl::mathop::! tcl::mathop::!= tcl::mathop::% tcl::mathop::& tcl::mathop::* tcl::mathop::** tcl::mathop::+ tcl::mathop::- tcl::mathop::/ tcl::mathop::< tcl::mathop::<< tcl::mathop::<= tcl::mathop::== tcl::mathop::> tcl::mathop::>= tcl::mathop::>> tcl::mathop::^ tcl::mathop::eq tcl::mathop::in tcl::mathop::ne tcl::mathop::ni tcl::mathop::| tcl::mathop::~
ex: tcl::mathop::+ 1 2 3 => 6
ex: tcl::mathop::< 1 2 3 => 1

== noise3
syn: noise3 x y z
does: Smooth noise of three coordinates, a float from -1 to 1, for shapes and textures. The same coordinates give the same value. The noise seed of the interpreter sets the pattern.
cost: a few compute units.
ex: expr {[noise3 0 0 0] == [noise3 0 0 0]} => 1
diff: Tcl has no `noise3`.
