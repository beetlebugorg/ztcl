# The command reference: the ztcl modules. Each has its own full page in
# docs/modules/. The format is in docs/reference/README.md.

== ztcl::vt
syn: ztcl::vt subcommand ?arg ...?
does: A terminal screen in memory: feed it the bytes of a program, and read its cells and its text.
page: modules/vt.md

== ztcl::wasm
syn: ztcl::wasm subcommand ?arg ...?
does: Runs WebAssembly modules in the sandbox and the limits of the interpreter: decodes and validates a module, links its imports to Tcl commands, other instances, or WASI preview 1, and calls its exports with Tcl values. Load it with `package require ztcl::wasm`.
sub: load fileName | Reads, decodes, and validates a module file, and gives a module handle. Needs the capability `file`.
sub: new bytes | Decodes and validates the bytes of a module, and gives a module handle.
sub: instantiate module ?option value ...? | Links the imports (`-imports`, `-link`, `-wasi`), runs the start function, and gives an instance handle.
sub: call instance function ?-limit units? ?-raw? ?--? ?arg ...? | Calls an export and gives its result, a list of its results, or an empty string.
sub: package fileName ?prefix? ?-wasi dict? | Loads a Tcl C package built for `wasm32-wasi` with `libztclstubs.a` and runs its init function. Needs the capability `file`.
sub: run module|fileName ?option value ...? | Runs a WASI command (`_start`) and gives its exit code.
sub: memory instance size|grow|read|write|string ?arg ...? | Reads, writes, and grows the linear memory of an instance.
sub: global instance name ?value? | Reads or sets an exported global.
sub: exports module|instance | A list of name, kind, and type for each export.
sub: imports module | A list of module, name, kind, and type for each import.
sub: info module | A dict of the counts and the features of a module.
sub: delete handle ?handle ...? | Deletes modules and instances.
sub: jit ?boolean? | Reads or sets the use of the JIT tier for the calls of the interpreter. Gives 1 when the JIT is on. The JIT is on by default on x86-64 Linux and macOS, and the interpreter runs elsewhere.
cost: one compute unit for each call and each loop pass of the wasm code
page: modules/wasm.md

== ztcl::probe
syn: ztcl::probe subcommand ?arg ...?
does: Records the values of a running script at a proc, a line, a command, a variable, or an error, with no change to the script, and gives the records back as dicts or JSON.
page: modules/probe.md

== ztcl::tls
syn: ztcl::tls socket ?-servername name? ?-alpn protocols? ?-cadata pem? ?-verify boolean? host port
does: A TLS 1.3 client: connects to `host` on `port`, runs the handshake, checks the certificate chain and the host name, and gives a channel. Load it with `package require ztcl::tls`.
sub: socket ?option value ...? host port | Opens the connection and gives the name of the channel. A failed handshake closes the connection and gives an error.
opt: -servername name | The DNS name for SNI and for the check of the certificate. The default is `host`.
opt: -alpn protocols | A list of up to 8 ALPN protocols.
opt: -cadata pem | The trust anchors as PEM text, in place of the store of the system.
opt: -verify boolean | With 0, the chain and the host name are not checked. The default is 1.
cap: socket
flags: --allow socket,channels
page: modules/tls.md
names: ztcl::tls::socket

== ztcl::gc
syn: ztcl::gc subcommand
does: Gives the counts of the collector of the heap of the interpreter tree: the pauses, the time of the marks and the sweeps, the bytes of the heap, the bytes that the program allocated, and the resident set of the process. The counts of time depend on the host.
cap: meter
flags: --allow meter
page: modules/gc.md
sub: ztcl::gc stats | A dict of the counts: `collections`, `gc_ns`, `mark_ns`, `sweep_ns`, `pause_p50_ns`, `pause_p99_ns`, `pause_max_ns`, `heap_bytes`, `heap_peak`, `live_bytes`, `used_bytes`, `threshold`, `allocated`, `freed`, `alloc_rate`, `uptime_ns`, `rss`, `rss_peak`, `returned`, and `retained`.
sub: ztcl::gc collect | Runs a collection now, where the build can collect.
sub: ztcl::gc reset | Starts the counts again.
ex: ztcl::gc reset
ex: dict get [ztcl::gc stats] collections => 0
ex: dict size [ztcl::gc stats] => 20
err: ztcl::gc nope | bad option "nope": must be collect, reset, or stats

== ztcl::meter
syn: ztcl::meter subcommand ?arg ...?
does: Counts the compute units, the time, the memory, and the I/O of threads and child interpreters, for a host that bills its customers. A compute unit is the same on each machine and with the JIT on or off. A record is a line of JSON in a hash chain, with an optional Ed25519 signature.
cap: meter
flags: --allow meter
page: modules/meter.md
sub: ztcl::meter create NAME ?-budget UNITS? ?-tenant TEXT? | Makes the meter NAME, or sets the options of the meter NAME. A budget caps the compute units of all the threads of the meter.
sub: ztcl::meter get NAME | The dict of the counts of NAME.
sub: ztcl::meter list | The names of the meters.
sub: ztcl::meter reset NAME | Sets each count of NAME to zero.
sub: ztcl::meter delete NAME | Removes NAME. A thread that counts in it goes on to count in it until it ends.
sub: ztcl::meter run NAME SCRIPT | Runs SCRIPT in the current interpreter and counts it in NAME. The budget of NAME caps the units of SCRIPT.
sub: ztcl::meter record NAME ?-tenant TEXT? ?-script TEXT? ?-sign? ?-key SEED? | The usage record of NAME: one line of JSON with the SHA-256 of the record before it. `-key` signs with the Ed25519 key of a 64-digit hex seed, and `-sign` with the key of the host.
sub: ztcl::meter verify RECORD PUBLICKEY | 1 when the signature of RECORD matches the hex public key, else 0.
sub: ztcl::meter pubkey SEED | The hex public key of a hex seed.
ex: ztcl::meter create demo -tenant acme => demo
ex: ztcl::meter run demo {set a 1; set b 2}; dict get [ztcl::meter get demo] units => 2
ex: ztcl::meter create small -budget 100 => small
ex: catch {ztcl::meter run small {while 1 {}}} msg; set msg => compute limit reached
err: ztcl::meter get nope | no meter "nope"

== ztcl::agent
syn: ztcl::agent subcommand ?arg ...?
does: Runs an LLM agent loop in an isolated thread with no capability, which holds only the data and the tools that the host gives it. The host posts each request to its one endpoint with its own headers, runs only its own tools, and checks the result against a schema. Load it with `package require ztcl::agent`.
cap: thread
flags: --allow thread
page: modules/agent.md
sub: ztcl::agent run ?-option value ...? | Runs the loop. Gives a dict of the result, the log, and the counts.
sub: ztcl::agent doc NAME TEXT ?ARG TYPE ...? | Sets the text of the tool NAME and the types of its arguments.
sub: ztcl::agent describe NAME | The spec of the command NAME as a tool: name, text, JSON schema, and parameters.
sub: ztcl::agent check SCHEMA VALUE | VALUE when it matches the result schema SCHEMA, else the error `ZTCL AGENT RESULT`.
sub: ztcl::agent schema SCHEMA | The JSON schema of a result schema.
sub: ztcl::agent post URL HEADERS BODY | One HTTP/1.1 POST of a JSON body. Gives `status N body TEXT`.
ex: package require ztcl::agent; ztcl::agent check {n int tags {list string}} {n 3 tags {a b}} => n 3 tags {a b}
ex: catch {ztcl::agent check {kind {enum a b}} {kind c}} msg; set msg => result.kind is not enum a b
ex: proc greet {name {times 1}} {}; lindex [ztcl::agent describe greet] 3 => {name required} {times optional}
ex: ztcl::agent schema {n int} => {"type":"object","properties":{"n":{"type":"integer"}},"required":["n"],"additionalProperties":false}

== ztcl::pdf
syn: ztcl::pdf subcommand ?arg ...?
does: Makes a PDF document: pages, text in embedded TrueType fonts, rectangles, lines, images, links, named places, the outline, and the document information.
sub: create ?-compress bool? | Makes a document and gives its handle.
sub: font doc bytes | Adds a TrueType font and gives its number.
sub: page doc ?width height? | Adds a page and gives its number. The default is A4.
sub: text doc page font size x y string ?-color rgb? ?-ligatures bool? | Shows text and gives its width.
sub: measure doc font size string | Gives the width of a string in points.
sub: rect doc page x y width height ?-fill rgb? | Fills a rectangle.
sub: line doc page x0 y0 x1 y1 ?-width w? ?-color rgb? | Strokes a line.
sub: image doc bytes | Adds a PNG or JPEG image and gives {number width height}.
sub: place doc page image x y width height | Shows an image in a rectangle.
sub: link doc page x0 y0 x1 y1 -uri url|-dest name | Makes a rectangle a link.
sub: dest doc name page x y | Names a place for a link.
sub: outline doc title level page y | Adds an entry to the outline.
sub: info doc key value | Sets the Title, Author, Subject, or Keywords.
sub: bytes doc | Gives the bytes of the PDF file.
sub: pages doc | Gives the count of pages.
sub: delete doc | Frees the document.
page: modules/pdf.md

== ztcl::typeset
syn: ztcl::typeset subcommand ?arg ...?
does: Breaks paragraphs into lines with the total-fit algorithm of Knuth and Plass, hyphenates words with the patterns of Liang, measures text in TrueType fonts, and lays out Markdown into the pages of a PDF document.
sub: break text -width w ?options? | Gives the lines of a paragraph, with the x position of each word.
sub: justify text -width columns ?options? | Gives justified lines of characters, for a terminal.
sub: svg text -width w -font font ?options? | Gives an SVG image of a paragraph.
sub: hyphenate word ?-lang en-us? | Gives the word with a hyphen at each place where it can break.
sub: pages counts -lines n ?-columns c? ?-gap g? | Places paragraphs in columns and pages with no widow or orphan line.
sub: font load bytes | Loads a TrueType font and gives its handle.
sub: font metrics font size | Gives the metrics of a font at a size.
sub: font measure font size string | Gives the width of a string in points.
sub: markdown doc text -fonts dict ?-style dict? ?-run prefix? | Lays out Markdown into new pages of a document.
sub: book doc chapters -fonts dict ?-style dict? ?-run prefix? | Lays out a list of Markdown chapters into new pages of a document.
ex: package require ztcl::typeset; ztcl::typeset hyphenate typesetting => type-set-ting
page: modules/typeset.md
